## 检查及限制

- 浏览器回归脚本：`scripts/result-leave-guard.test.cjs`。需要启动本机 Next 开发服务及已安装的 Chrome；默认使用旁边 `essmote-admin` 仓库的 Playwright，也可以通过 `PLAYWRIGHT_MODULE` 指定现有模块路径。
- 脚本创建临时 `.local` 测试入口，加载真实客户端组件；结束后自动删除入口。所有 API 均被拦截，生成调用数为 0；测试放弃状态只保存在测试脚本内存。
- `pnpm exec tsc --noEmit --incremental false`：现有 42 个类型错误；与通过 `git archive HEAD` 提取的修改前源码对照，诊断完全一致（仅忽略路径前缀和改动导致的行号）。没有新增类型错误。
- `pnpm lint`：仓库没有 ESLint 配置，命令进入首次配置向导，无法作为通过项；本次没有扩大范围添加或重写全仓配置。
- 本地 Next 开发服务已编译所涉及组件；`git diff --check` 无错误。
- 本地常规路由出现指向自身的 307 重定向，隔离入口不依赖该语言路由中间件。真实登录页到成稿页、真实数据库持久化及生产浏览器端到端本轮未验证；没有修改语言路由规则。
- 浏览器历史只在现有 tracker 已记录索引的同应用条目中显示自定义提醒。无索引、跨文档历史使用浏览器原有行为，不伪造或堆叠历史条目。
- 刷新、关闭标签使用现有原生 beforeunload 提醒，其显示由浏览器决定。断网、崩溃、强制退出不能保证拦截；这些操作不会静默请求放弃资格。
- 已实际检查 TXT 下载；PDF/Word 完整排版、真实优化任务和真实服务端扣次未重新执行。本次没有修改它们的实现。

## 常规页面验收步骤（部署后）

1. 在创作中心打开一篇已经生成并保存、且还没使用免费优化的 PS/SOP/CL/RL。
2. 点击标题上方“返回创作中心”，应看到选定样式及固定文案。关闭弹窗后仍在正文页，免费机会保留。
3. 分别点击 Logo、购买方案、教程、人工润色、联系我们、顶部创作中心及头像菜单里的我的文档，应出现同一提醒。只展开菜单不会提醒。
4. 点击“使用免费优化”，应打开原来的优化设置；取消设置后不消耗机会、不开始生成。
5. 再次点击某个导航，选择“我已了解，直接离开”，保存放弃状态成功后应去原本点击的目的地。重新打开这篇文书，原文仍可查看，免费机会不会恢复。
6. 在有正文的页面复制、导出、切换版本、查看对比，应只执行对应操作。已经使用或放弃免费优化的文书正常离开。
